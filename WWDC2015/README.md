# WWDC2015 Session Summaries

Detailed, API-focused Markdown summaries of WWDC15 developer sessions that have a published transcript — **11 sessions** (the DunfeyHotel archive lists few transcripted sessions this far back), organized into topic folders. Each note captures the session's frameworks and APIs (new ones flagged **[NEW]**), key concepts, and code highlights. (WWDC15 introduced watchOS 2 native apps, Swift 2, and App Thinning. Session 719 is unavailable on Apple's site.)

Built from Apple's session pages at developer.apple.com. Session list curated from dunfeyhotel.com/transcripts.
