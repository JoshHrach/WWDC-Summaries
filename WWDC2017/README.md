# WWDC2017 Session Summaries

Detailed, API-focused Markdown summaries of WWDC17 developer sessions that have a published transcript — **35 sessions** (the DunfeyHotel archive lists 35 transcripted 2017 sessions, skewed toward design talks), organized into topic folders. Each note captures the session's frameworks and APIs (new ones flagged **[NEW]**), key concepts, and code highlights. (WWDC17 introduced Core ML, ARKit, Vision, drag-and-drop, and Metal 2.)

Built from Apple's session pages at developer.apple.com (abstracts, chapter-by-chapter summaries, code samples, and resource links). Session list curated from dunfeyhotel.com/transcripts.
