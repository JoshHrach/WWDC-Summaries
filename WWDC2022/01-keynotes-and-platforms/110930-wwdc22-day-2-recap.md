# WWDC22 Day 2 recap
**WWDC22 · Session 110930** · [Watch](https://developer.apple.com/videos/play/wwdc2022/110930/)

_Platforms:_ iOS 16, iPadOS 16, macOS Ventura 13

## Overview
A short (~1.5 minute) highlight reel of Day 2 sessions at WWDC22. The clip recaps the key developer sessions from Tuesday and teases what is coming on Day 3. Highlights include: new SwiftUI navigation APIs (NavigationStack, NavigationSplitView — "The SwiftUI cookbook for navigation"), Xcode 14 deep-dive features, Unity plug-ins for Apple frameworks (Core Haptics and others in the Apple Unity Plug-ins package), 3D room scanning with RoomPlan, SF Symbols Variable Color adoption, and the new Push to Talk framework for iOS walkie-talkie style communication.

## Key Topics

### SwiftUI Navigation
New navigation APIs — NavigationStack and NavigationSplitView — provide programmatic, data-driven navigation in SwiftUI apps. Covered in depth in session 10054 "The SwiftUI cookbook for navigation."

### Xcode 14 Features
Deep-dive on Xcode 14 improvements introduced at Day 1, including build performance, editor improvements, and previews. Covered in session 110427 "What's new in Xcode."

### Unity Plug-ins for Apple Frameworks
Apple frameworks — including Core Haptics — are now available as Unity plug-ins, making it easier to integrate Apple platform capabilities into Unity-based game projects. Covered in session 10065.

### RoomPlan
New ARKit-powered framework for creating parametric 3D scans of rooms, enabling accurate floor plans and room models from iPhone LiDAR. Covered in session 10127.

### SF Symbols Variable Color
Variable Color lets SF Symbols express a continuous value (e.g., signal strength, volume) by activating layers progressively. Covered in session 10158 "Adopt Variable Color in SF Symbols."

### Push to Talk Framework
New framework for iOS enabling walkie-talkie style push-to-talk voice communication in apps. Covered in session 10117 "Enhance voice communication with Push to Talk."
