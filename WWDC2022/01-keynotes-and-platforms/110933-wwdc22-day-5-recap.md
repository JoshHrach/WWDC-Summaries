# WWDC22 Day 5 recap
**WWDC22 · Session 110933** · [Watch](https://developer.apple.com/videos/play/wwdc2022/110933/)

_Platforms:_ iOS 16, iPadOS 16, macOS Ventura 13, tvOS 16

## Overview
A short (~1.5 minute) closing highlight reel for the final day (Friday) of WWDC22. The clip wraps up the week's sessions with mentions of: improving battery consumption in apps (power profiling, display power optimization), building Swift server apps alongside iOS apps in Xcode using Swift on Server (bridging server and client with shared Swift code), ShazamKit custom catalog updates for matching audio to video at scale, creating multiple windows in iPad apps, and connecting devices to Apple TV for multiplayer games using the GameKit/MultipeerConnectivity APIs.

## Key Topics

### Improve Battery Consumption
Session covering Xcode Instruments power profiling and techniques to reduce display and CPU energy use in apps — display is called out as a major power source.

### Swift Server Apps in Xcode
Session demonstrating building a server-side Swift app alongside an iOS app in the same Xcode workspace, sharing Swift code between client and server to reduce the technology gap.

### ShazamKit Custom Catalogs
Session covering updates to ShazamKit's custom catalog APIs — new tools for working with large audio catalogs at scale for audio/video synchronization use cases.

### Multiple Windows on iPad
Session covering `UIWindowScene`, `UISceneActivationConditions`, and related APIs for creating and managing multiple windows in iPad apps (shown with a book-tracking app example).

### Device-to-Device with Apple TV
Session showing how to connect iOS/iPadOS devices to Apple TV for multiplayer experiences (tic-tac-toe demo), using GameKit or MultipeerConnectivity.
