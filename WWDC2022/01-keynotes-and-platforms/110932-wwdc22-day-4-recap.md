# WWDC22 Day 4 recap
**WWDC22 · Session 110932** · [Watch](https://developer.apple.com/videos/play/wwdc2022/110932/)

_Platforms:_ iOS 16, iPadOS 16, macOS Ventura 13

## Overview
A short (~1.5 minute) highlight reel of Day 4 (Thursday) sessions at WWDC22. The clip recaps Thursday's sessions and teases the final day. Highlights include: organizing iPad interfaces with SwiftUI (NavigationSplitView, programmatic navigation state restoration), using SwiftUI with UIKit (UIHostingController and UIHostingConfiguration), Vision framework updates (new optical flow revision), creating compelling SharePlay experiences, and writing for interfaces (UX writing principles from Apple's interface writers).

## Key Topics

### SwiftUI on iPad: Organize Your Interface
Session 10058 covers using `NavigationSplitView` and programmatic navigation state with `NavigationPath` for state restoration and deep linking in iPad apps.

### Use SwiftUI with UIKit
Session 10072 covers `UIHostingController` for embedding SwiftUI views in UIKit view controllers, and `UIHostingConfiguration` for using SwiftUI views as `UICollectionView`/`UITableView` cell content.

### What's New in Vision
Session 10024 covers new Vision framework request revisions: optical flow Revision 2 (ML-based, `VNGenerateOpticalFlowRequestRevision2`), text recognition Revision 3 with auto language detection, and barcode detection Revision 3.

### Make a Great SharePlay Experience
Session 10139 covers design and technical best practices for building Group Activities / SharePlay experiences that feel like everyone is in the same space.

### Writing for Interfaces
Session 10037 covers UX writing principles (PACE: Purpose, Anticipation, Context, Empathy) from Apple's interface writers — how to make app text clear, conversational, and accessible.
