# WWDC2014 Session Summaries

Detailed, API-focused Markdown summaries of WWDC14 developer sessions that have a published transcript — **6 sessions** (the DunfeyHotel archive lists few transcripted sessions this far back), organized into topic folders. Each note captures the session's frameworks and APIs (new ones flagged **[NEW]**), key concepts, and code highlights. (WWDC14 introduced Swift, Metal, HealthKit, HomeKit, and app extensions.)

Built from Apple's session pages at developer.apple.com. Session list curated from dunfeyhotel.com/transcripts.
