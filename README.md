# WWDC Session Summary Library

A browsable reference of detailed, API-focused Markdown summaries of Apple WWDC developer sessions, spanning **2014–2026**. One file per session, grouped into topic folders, with new/changed APIs flagged **[NEW]**. Each year has its own README index.
