# WWDC2016 Session Summaries

Detailed, API-focused Markdown summaries of WWDC16 developer sessions that have a published transcript — **16 sessions** (the DunfeyHotel archive lists few transcripted sessions this far back), organized into topic folders. Each note captures the session's frameworks and APIs (new ones flagged **[NEW]**), key concepts, and code highlights. (WWDC16 introduced SiriKit, iMessage apps, and Swift 3.)

Built from Apple's session pages at developer.apple.com. Session list curated from dunfeyhotel.com/transcripts.
