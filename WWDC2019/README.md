# WWDC2019 Session Summaries

Detailed, API-focused Markdown summaries of every WWDC19 developer session that has a published transcript — **150 sessions**, organized into topic folders. Each note captures the session's frameworks and APIs (new ones flagged **[NEW]**), key concepts, and code highlights. (WWDC19 introduced SwiftUI, Combine, Catalyst, and Sign In with Apple.)

Built from Apple's session pages at developer.apple.com (abstracts, chapter-by-chapter summaries, code samples, and resource links). Session list curated from dunfeyhotel.com/transcripts.
