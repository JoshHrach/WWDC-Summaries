# WWDC2018 Session Summaries

Detailed, API-focused Markdown summaries of WWDC18 developer sessions that have a published transcript — **38 sessions** (the DunfeyHotel archive lists 38 transcripted 2018 sessions), organized into topic folders. Each note captures the session's frameworks and APIs (new ones flagged **[NEW]**), key concepts, and code highlights. (WWDC18 introduced Siri Shortcuts, Create ML, ARKit 2, USDZ, and Network.framework.)

Built from Apple's session pages at developer.apple.com (abstracts, chapter-by-chapter summaries, code samples, and resource links). Session list curated from dunfeyhotel.com/transcripts.
